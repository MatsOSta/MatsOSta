# Hi, I'm Mats

Senior Solutions Architect working across infrastructure, platform engineering, security, and automation.

My professional background is in regulated financial IT: Linux/RHEL, OpenShift/Kubernetes, Python and shell automation, GitOps, identity systems, observability, vulnerability management, and the occasional production system that has accumulated more history than anyone intended.

## How I think about engineering

I like finding friction.

Repeated manual work, undocumented operational knowledge, systems that depend on one person, and processes everyone has learned to work around are usually signs that engineering work remains to be done.

My goal is **replaceability by design**: automate what should be automated, make knowledge transferable, and build systems that other engineers can understand and operate.

Not to run out of work — to buy back the team's capacity to solve newer problems, learn, and adopt better tools.

## The general rule

Find a problem. Understand why it exists. Fix it. Make the fix maintainable by someone else.

Then go looking for the next one.
